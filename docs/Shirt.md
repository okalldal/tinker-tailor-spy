## Customization Options


### Collar


#### Collar

- **Classic** (`CCC1`) — This versatile collar features a short spread and classic sharp points.
- **Classic Widespread** (`CCCWS11`) — This collar style features ample space between subtly outwardly oriented points, and a collar length closer to a classic point collar.

- **Point** (`MCK11B`) — This straight collar features typical sharply angled points and narrow spread but is overall enlarged for a more pronounced look.
- **Button Down** (`CCLRBD`) — This style features a relatively short spread, small buttons, and a more pronounced rolling “gap” for a touch of sophisticated detail.
